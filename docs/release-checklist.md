## 核验方法与边界

发布前分别检查最终文件、构建包和 Git author/committer。核对目标仓库当前 Code 页与本地 `origin`，不要根据项目展示名猜测仓库地址。远程分支的提交 ID 应与本地交付一致，Actions 中的 Python checks 必须属于该提交；网络不可达或无法读取 CI 时保留未核验状态。

如果需要清理已经公开的历史，单独处理全部相关引用并核对更新范围。只增加一条新提交不能去除旧记录，改写历史也不能保证移除第三方副本或缓存。此过程不把个人信息写入提交说明、公开检查记录或示例。

画面、点击路径和真实模型偏好各自需要相应证据。单测、规则脚本、协议操作和安装包资源检查不能替代它们。测试服务器、临时数据库、专用进程与临时安装目录应在结束后回收，仅保留必要的小型报告。
