## 实际结果

最终代码包含 **28 项轻量检查**，均已通过：引擎 11 项、服务 7 项、HTTP 7 项、stdio 协议 3 项。初始 27 项集成运行记录见 `../evidence/tests.log`（本机档案）；之后修复畸形 MCP 工具名处理并加入跨协议共享状态用例，受影响的 3 项协议检查通过，见 `../evidence/protocol-followup.txt`（本机档案）。修改后的实验计划也逐一经严格 start 参数校验接受。

完整真实 HTTP 路径由 `scripts/verify_demo.py` 执行：

1. 本机临时回环服务启动，网页请求成功，初始状态 waiting。
2. 独立 `clients.rule_agent` 进程发现规则并创建会话；种子 42，完成 24 回合。
3. Pattern 解题、Resonance 风格变化及深入、Creation 组合与变换、存档均经过真实接口。第 14 回合花费 2 Energy 重玩 Pattern，最终剩余 5 Energy，按回合上限结束。
4. 每一步观察、动作和结果保存为 `../evidence/full-session.jsonl`（本机档案）；完整前后状态保存为 `../evidence/session-export.json`（本机档案）。逐步回放 24 次转换，完全一致，见 `../evidence/replay.json`（本机档案）。
5. 关闭并重新打开同一个 SQLite 数据库，观察完全恢复，回放再次通过。
6. 独立通用模型客户端连接一个明确标记的本地 Chat Completions **脚本模拟端点**，24 次请求完成 24 回合。它验证兼容协议与客户端循环，不代表真实语言模型测试。
7. 随机玩家经 HTTP 进行 5 回合后主动离开。每个演示会话均可回放。

重复实验管线另执行一次：相同玩家在 control 与 personalized 条件各完成两局，每局 24 回合，四局回放全部一致。计划使用匹配种子和随机条件顺序，见 `../evidence/experiment/plan.json`（本机档案）、`../evidence/experiment/comparison.json`（本机档案） 和 `../evidence/experiment/raw-export.json`（本机档案）。这些样本来自预定规则脚本，只验证实验软件。

## 覆盖的关键边界

- 相同初始状态、种子和行动序列生成相同结果；转换不修改传入快照。
- 正常观察与公开事件隐藏随机种子和未发现答案；完整调试限定研究模式，正常会话未结束时原始导出受阻。
- 未知动作、非法参数、过期版本、畸形 JSON 和畸形 MCP 工具名返回错误；被拒动作不增加事件。
- 同一玩家不能绑定不同模型；normal/research 画像分开。重置采用事务边界，保留原始历史。
- 两个会话状态隔离；重复提交只有一次成功。多个数据库连接共用持久状态。
- JSONL 执行进入动作，MCP 对同一存档执行创造与退出，服务可读到最终图并验证完整回放。
- 活动超时、心跳恢复、多会话和结束提示通过服务时钟检查。HTTP 创建和结束会话确实改变状态响应。
- HTTP Bearer 认证、远程无令牌拒绝、基本限流、正文限制、Host/Origin 防护已检查。
- 网页 HTML/CSS/JS 和状态端点检查通过；断线代码会清除旧绿灯。

## 未验证及已知限制

- **没有真实商业模型或开放权重模型游玩结果。** 未使用真实服务凭证。通用适配器要求供应商支持 Chat Completions JSON object 输出。
- **没有浏览器视觉或交互验收。** 无法保证测试窗口从创建起位于副屏，所以按全局窗口约束跳过。没有截图与参考图，不执行 `visual-verdict` 打分；源码和状态接口检查不等同于画面验证。
- MCP 用真实 stdio JSON-RPC 子进程验证，未在第三方聊天产品中实际配置；只实现 stdio，不实现 MCP Streamable HTTP。
- 九个区域和六种信号使用有限的规则内容，没有生成模型、训练或无限内容。个性化只调整呈现顺序，不改变刺激难度。
- 成本没有收益差异，但完成步数、内容和负担仍有混淆。统计区间含样本量与定义；同局行动相关、样本少，不能据此断言稳定偏好、因果效应或快乐。
- SQLite 适合本机和小规模并行会话。未做压力测试；基本 IP 限流与共享访问令牌不构成生产级多租户系统。公网接入需要 TLS 代理。
- 内部激活和情绪探针为 unavailable，只预留外部扩展契约，未伪造采样数据。
